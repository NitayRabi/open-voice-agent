Advanced: use an existing model file

The voice model just talks. It has one tool — delegate_task — and calls it when something actually needs doing. The task then goes to a single, more capable model behind an OpenAI-compatible endpoint (the "brain"), and its answer is spoken back.

Nothing heavy ships in the installer. Download a local model here (stored under the app data dir), or use a remote endpoint instead (Delegation tab). Downloads resume and are verified.

Advanced: Hugging Face authentication

The built-in models, including Gemma 4 E4B, do not require a token. Add one only if anonymous download limits become a problem.
