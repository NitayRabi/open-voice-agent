or

You can use the same GGUF for conversation and delegation, or install another model from the Models tab. Leave the executable field blank to have the app install and manage llama.cpp for you.

Tasks go to the agent through acpx over the Agent Client Protocol. acpx (and Node.js, if needed) is installed automatically. The agent signs in with its own account, and by default may read files but not change anything.

Step 3 of 3

Ready to start

The voice engine will start automatically. You can change the conversational model or delegation provider later in Settings.

Default agent settings

The voice model just talks. It has one tool — delegate_task — and calls it when something actually needs doing. The task then goes to the "brain" — a more capable model behind an OpenAI-compatible endpoint, or a coding agent such as Claude Code or Codex driven over ACP — and its answer is spoken back.
